# استراحة WebView V2
تطبيق Android WebView للموقع: http://e7.net:888/

## الجديد في V2
- شاشة بدء أصلية على Android 12+ وأيقونة تطبيق.
- دعم JavaScript وDOM Storage والكوكيز والمحتوى المختلط HTTP/HTTPS.
- تشغيل الفيديو والبث بملء الشاشة مع تدوير مناسب.
- اختيار/رفع الملفات من صفحات الويب.
- تنزيل الملفات عبر DownloadManager مع إشعار اكتمال.
- شاشة خطأ عربية وزر إعادة المحاولة عند تعذر فتح الصفحة الرئيسية.
- حفظ حالة WebView والتنقل بزر الرجوع.

## البناء
افتح المجلد في Android Studio، نفّذ Gradle Sync ثم Run. لإنشاء APK: Build > Build APK(s).

ملاحظة: الموقع يستخدم HTTP، لذلك المشروع يسمح cleartext للمضيف e7.net. يفضّل HTTPS مستقبلاً إن كان الخادم يدعمه.
